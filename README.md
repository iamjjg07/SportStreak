# SportStreak

A clean and professional personal sports tracker.

Track your daily activity, build streaks, plan your week, and export to Google Calendar.

**Sports included:**
- Track: Running, Jogging, Long Jump
- Team: Football, Volleyball, Basketball
- Racket: Table Tennis, Lawn Tennis, Badminton
- Gym: Gym
- Water: Swimming

---

## Features

- 11 sports organized in categories
- Daily streak system
- Motivational quote every day
- Dark Mode & Light Mode
- Weekly Schedule planner
- “Today’s Plan” on the home page
- Activity Timer
- Export week to Google Calendar (.ics file)
- Fully responsive (works on phone and computer)
- Data saved in your browser (no account needed)

## How to Use on GitHub

1. Create a new repository named `SportStreak`
2. Upload these 4 files
3. Go to **Settings → Pages**
4. Select source: `main` branch and `/ (root)`
5. Wait 1–2 minutes
6. Open the link shown in Pages settings

---

## How to Use the App

1. Click any sport to track your streak
2. Use the Timer while training
3. Go to **Schedule** tab to plan your week
4. Click **Add to Google Calendar** to download the .ics file
5. Import the file in Google Calendar (Settings → Import & export)
