# SportStreak

Personal sports tracker for GitHub Pages.

## Sports
Track: Running, Jogging, Long Jump
Team: Football, Volleyball, Basketball
Racket: Table Tennis, Lawn Tennis, Badminton
Gym, Swimming

## Features
- Hero photos rotate every 5 seconds
- Quotes change by time: morning from 6:00, afternoon from 12:00, evening from 16:00
- Category tabs, streaks, history
- Calendar with a tick for done days and an X for missed days
- Round timer buttons: green start, pause bars, red stop
- Weekly schedule
- Opens Google Calendar to save each planned day
- Alarm based on the schedule (works while the page is open)
- Reset and restore records
- Time spent: seconds, minutes, hours, days, weeks, months, years
- Share code friends can paste from any chat app
- Save messages say “Saved successfully”

## Limits
GitHub Pages is a static site. It cannot log into Google for you or host a live friend network. Google Calendar opens in a new tab so you can save the event. Friend codes stay on this device.

## Deploy
Upload these files to a GitHub repo, then Settings → Pages → main branch / root.
